# oy_all-the-better_proposal

올리브영 PB **올더베러(All the Better)** 브랜드 빌딩 캠페인 제안서 작업 저장소.

2026년 하반기 올리브영 플랫폼 PB 마케팅 대행사 선정 입찰의 **올더베러 과제**에 대응하기 위한 제안 문서를 정리한다.

## 제안의 핵심

> "올더베러는 안 팔려서가 아니라, 기억에 안 남아서 1위가 아니다."

'우연 → 의도'로 바꾸는 **각인 설계**가 캠페인의 코어. 시그니처 키워드 **「채우다」** 를 선점하고, 심의-프리 일반식품 선집행 → 구미 순차 투입, 올리브영을 미디어로 활용, 챌린저스로 올영세일 랭킹을 견인해 **올리브영(올리브베러) 1위**를 목표로 한다.

## 제안서 구조 (PART 0 ~ 10)

- **PART 0** 우리가 이해한 과제 (RFP 재해석)
- **PART 1** 진단 — "팔리는데, 기억되지 않는 브랜드"
- **PART 2** 전략 — "우연을 의도로" (각인 설계)
- **PART 3** 제품별 RTB & 메시지 정교화
- **PART 4** 크리에이티브 & 콘텐츠 솔루션
- **PART 5** 실행 프로그램 — 옴니채널 프로그램 믹스
- **PART 6** 심의 대응 체계 (차별화 포인트)
- **PART 7** 하반기 운영 로드맵
- **PART 8** 성과 체계 (KPI)
- **PART 9** 운영 체계 & 견적
- **PART 10** Why Us — 마무리
